Keep 5-8 hashtags. Cover text suggestion goes under each part.

## Posting plan
- One part per day at the same time; pin Part 1 so new viewers start from the beginning.
- Comment "Part N is up" under the previous part.
- Count A/B comments before writing the next part; if few come, decide yourself.
